# M2AC

Project homepage for **"Language-Mediated Multimodal Reasoning for Agile Coordination of Uncrewed Surface Vehicle Swarms"**.

**Live page:** <https://jasonli0012.github.io/M2AC/> — served directly by GitHub Pages; no local deployment needed.

- `index.html` — project page (static site)
- `assets/` — result figures, demo video (`assets/M2AC.mp4`), and video poster
- `dataset/` — dataset description and [download link (Baidu Netdisk)](https://pan.baidu.com/s/16j_rYS9jQJlKVoRFpHwkqg?pwd=my2c)

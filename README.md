# M2AC

Project homepage for **"Language-Mediated Multimodal Reasoning for Agile Coordination of Uncrewed Surface Vehicle Swarms"**.

- `index.html` — project page (serve with GitHub Pages or any static server)
- `assets/` — result figures and demo video (currently a placeholder clip)
- `dataset/` — dataset description; downloads coming soon

## Preview locally

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

# M2AC Dataset

This repository hosts the dataset accompanying **"Language-Mediated Multimodal Reasoning for Agile Coordination of Uncrewed Surface Vehicle Swarms"**.

## Water-surface scene dataset (~18k images)

A self-built image dataset for water-surface scene comprehension, spanning four scene categories:

| Scene category      | Train  | Test |
|---------------------|--------|------|
| Open waters         | 5,052  | 430  |
| Open target         | 3,552  | 344  |
| Constrained passage | 4,706  | 405  |
| Constrained target  | 3,499  | 377  |
| **Total**           | 16,809 | 1,556 |

- **Training set**: self-collected at Songshan Lake.
- **Test set**: compiled from open-source water-surface datasets, covering diverse environments (rivers, streams, harbors) beyond the training lake.

## Field-trial logs

Multi-USV rosbag logs from the real-world lake experiments, including formation switching, unseen-lake transfer, human guidance and correction reuse, and narrow-passage traversal.
